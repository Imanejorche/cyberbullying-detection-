# Cyberbullying Detection using NLP and Machine Learning

## Project Overview

This project focuses on the automatic detection of toxic comments using Natural Language Processing and machine learning classification models.

## Project Work

- Text preprocessing
- TF-IDF vectorization
- Training and comparison of classification models
- Model evaluation
- Streamlit interface for prediction

## Models Used

- Logistic Regression
- Multinomial Naive Bayes
- LinearSVC

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Jupyter Notebook

## Project Files

- `app.py`: application interface for comment prediction
- `cyberbullying_detection.ipynb`: notebook containing the data preparation and machine learning workflow
- `model.pkl`: saved classification model
- `tfidf.pkl`: saved TF-IDF vectorizer

## Project Context

Project completed as part of a team-based academic project.
